EMBERLINE is a round-based tactical FPS in three.js: two teams of five, a bomb to plant or defuse, money earned each round and spent in a buy menu, and gunfire where stopping to aim pays. Single-player against bots, from plain static files with no build step and no network at runtime. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Click to play: WASD to move, mouse to look, click to fire, R to reload, Ctrl to crouch, Space to jump, B for the buy menu between rounds, E to plant or defuse the charge, 1/2 to swap weapons, 3 for a frag grenade, 4 for smoke.
